Deep Learning for False-Call Reduction in Automated X-Ray Inspection

Publication: High-Volume Electronics Manufacturing with Automated X-Ray Inspections

Developed an imbalance-aware deep-learning pipeline for automated X-ray inspection using ResNet-18, transfer learning, decision-threshold optimisation and false-call reduction analysis for high-volume electronics manufacturing. Handled a severe 91:1 class imbalance using Youden Index-based threshold optimisation to preserve defect sensitivity while reducing false positives.
